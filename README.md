# fluidSimulation
для запуска решателей описанных в работе по векторизации и верефикации 
необходимо запускать фаил в котором описан решатель 
установить зависимости у используемого интропретатора описаные ниже
поменять настройки этих решателей можно в paper_config.py

(CPU реализация без векторизации)
scalar_paper.py, - python >3.10..<3.15 + JIT
(CPU реализация с векторизации)
vector_paper.py, - python >3.15..<3.15 + numpy
(GPU реализация с векторизации в двух режимах fp32 и fp64)
gpu_vector_paper.py, python >3.15..<3.15 + pyopencl + numpy + видеокарта

зависимости решателя с графическим режимом описаны в pyproject.toml
